# 🏠 Arnando — Платформа управления арендой для самозанятых

Полнофункциональная веб-система для самозанятых арендодателей недвижимости, автоматизирующая управление объектами, договорами аренды, платежами и расходами для корректного расчета налогов.

Проект разработан в рамках кейс-чемпионата и решает проблему учета доходов и расходов при сдаче недвижимости в аренду для плательщиков налога на профессиональный доход (НПД).

## ✨ Ключевые возможности

### 🖥 Фронтенд (Веб-интерфейс)
- 📊 **Интерактивный дашборд** — визуализация ключевых метрик и статистики
- 🏢 **Управление объектами недвижимости** — добавление, редактирование, просмотр объектов
- 📄 **Управление договорами аренды** — создание и отслеживание договоров с арендаторами
- 💰 **Учет платежей и расходов** — фиксация всех финансовых операций
- 🧮 **Калькулятор налогов** — расчет налога на профессиональный доход (НПД)
- 📈 **Аналитика** — графики и отчеты по доходам/расходам
- 👤 **Профиль пользователя** — управление персональными данными и настройками

### ⚙️ Бэкенд (REST API)
- 👤 **Управление профилем арендодателя**: Хранение персональных данных, паспортной информации, ИНН, СНИЛС и банковских реквизитов
- 🏢 **Учет недвижимости**: Регистрация объектов аренды с детальной информацией
- 📄 **Договоры аренды**: Создание и управление договорами с физическими и юридическими лицами
- 💰 **Учет платежей**: Отслеживание всех поступлений от арендаторов
- 💸 **Учет расходов**: Фиксация расходов на содержание недвижимости
- 🔐 **JWT аутентификация**: Безопасный доступ с использованием JSON Web Tokens

## 🏗 Архитектура проекта

### Frontend
- **Технологии**: Чистый HTML5, CSS3, JavaScript (Vanilla JS)
- **Структура**: Многостраничное приложение с отдельными HTML-страницами
- **Стилизация**: Кастомные CSS стили

- **Framework**: FastAPI (Python)

- **ORM**: SQLAlchemy 2.0
- **Migrations**: Alembic

## 📊 Модель данных

### 👤 User (Пользователь / Арендодатель)
- Персональные данные: email, ФИО, телефон
- Документы: паспортные данные, ИНН, СНИЛС
- Финансы: банковские реквизиты (название банка, счет, БИК)
- Тип: самозанятый (`self_employed`)

### 🏢 Property (Объект недвижимости)
- Название и адрес объекта
- Тип: квартира, дом, коммерческая недвижимость
- Характеристики: площадь, количество комнат
- Базовая ставка аренды
- Связь с владельцем (User)

### 📄 Contract (Договор аренды)
- Арендатор: ФИО/название, тип (физическое/юридическое лицо)
- Объект недвижимости (связь с Property)
- Срок действия: даты начала и окончания
- Финансовые условия: сумма аренды, график платежей
- Статус: активный/завершенный

### 💰 Payment (Платеж)
- Сумма поступления
- Дата платежа
- Связь с договором аренды (Contract)

### 💸 Expense (Расход)
- Сумма расхода
- Описание (коммунальные услуги, ремонт и т.д.)
- Дата расхода
- Связь с объектом недвижимости (Property)

## 🔌 API Endpoints

### Аутентификация
- `POST /token` — получение JWT токена
- `POST /users/` — регистрация нового пользователя
- `GET /users/me/` — получение данных текущего пользователя

### Управление недвижимостью
- `GET /properties/` — список всех объектов пользователя
- `POST /properties/` — создание нового объекта
- `GET /properties/{id}` — получение деталей объекта
- `PUT /properties/{id}` — обновление объекта
- `DELETE /properties/{id}` — удаление объекта

### Управление договорами
- `GET /contracts/` — список всех договоров
- `POST /contracts/` — создание нового договора
- `GET /contracts/{id}` — получение деталей договора
- `PUT /contracts/{id}` — обновление договора
- `DELETE /contracts/{id}` — удаление договора

### Учет платежей
- `GET /payments/` — список всех платежей
- `POST /payments/` — регистрация платежа
- `GET /payments/{id}` — детали платежа
- `PUT /payments/{id}` — обновление платежа
- `DELETE /payments/{id}` — удаление платежа

### Учет расходов
- `GET /expenses/` — список всех расходов
- `POST /expenses/` — регистрация расхода
- `GET /expenses/{id}` — детали расхода
- `PUT /expenses/{id}` — обновление расхода
- `DELETE /expenses/{id}` — удаление расхода

> 💡 **Полная документация API** доступна после запуска приложения по адресу `/docs` (Swagger UI) или `/redoc` (ReDoc).

## 🚀 Установка и Запуск

### Локальный запуск

#### 1. Клонирование репозитория
```bash
git clone https://github.com/Amontapelir/arnando.git
cd arnando
```

#### 2. Настройка Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows

pip install -r requirements.txt
```

#### 3. Настройка переменных окружения
Создайте файл `.env` в папке `backend/`:

```env
DATABASE_URL=postgresql://user:password@localhost:5432/rent_tax_db
SECRET_KEY=your-secret-key-here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=1440
```

#### 4. Инициализация базы данных
```bash
# Создание таблиц
python -c "from app.database import Base, engine; Base.metadata.create_all(bind=engine)"

# Или с использованием Alembic (рекомендуется)
alembic upgrade head
```

#### 5. Запуск Backend
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend будет доступен по адресу: `http://localhost:8000`  
Документация API: `http://localhost:8000/docs`

#### 6. Запуск Frontend

Откройте файл `docs/index.html` в браузере или используйте любой локальный веб-сервер:

```bash
# Вариант 1: Python HTTP сервер
cd docs
python -m http.server 3000

# Вариант 2: Node.js (если установлен)
npx serve docs
```

Frontend будет доступен по адресу: `http://localhost:3000`

---

### Запуск через Docker

#### 1. Сборка образа Backend
```bash
cd backend
docker build -t arnando-backend .
```

#### 2. Запуск контейнера
```bash
docker run -d \
  --name arnando-backend \
  -p 8000:8000 \
  -e DATABASE_URL=postgresql://user:password@host:5432/rent_tax_db \
  -e SECRET_KEY=your-secret-key \
  arnando-backend
```

### Деплой на Render

Проект готов к деплою на платформу Render. Конфигурация находится в файле `render.yaml`:

1. Зарегистрируйтесь на [Render](https://render.com)
2. Подключите репозиторий GitHub
3. Render автоматически прочитает `render.yaml` и создаст:
   - Web Service для backend (Docker)
   - PostgreSQL базу данных `rent_tax_db`
4. Frontend можно захостить на GitHub Pages, Netlify или Vercel

## 🔐 Безопасность

- **JWT токены**: Все защищенные эндпоинты требуют валидный JWT токен
- **Хеширование паролей**: Пароли хранятся в хешированном виде (bcrypt)
- **Изоляция данных**: Каждый пользователь видит только свои данные
- **Валидация входных данных**: Pydantic схемы обеспечивают строгую валидацию
- **Защита от SQL-инъекций**: Использование SQLAlchemy ORM

## 🎯 Кейс-чемпионат

Проект разработан для решения реальной проблемы самозанятых арендодателей:

### Проблема
Сложность учета множества объектов, договоров и платежей для корректного расчета налога на профессиональный доход (НПД).

### Решение
Централизованная веб-система с:
- Автоматизацией учета объектов и договоров
- Отслеживанием всех финансовых операций
- Калькулятором для расчета налогов
- Аналитикой и визуализацией данных

### Целевая аудитория
Самозанятые граждане РФ, сдающие недвижимость в аренду
